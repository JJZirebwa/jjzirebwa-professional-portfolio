## Local site development

The Astro site uses Node 22, matching the Netlify deployment runtime. The repository root delegates npm commands to the site, so a new VS Code terminal can start development without changing folders:

```bash
nvm use
npm run setup
npm run dev
```

After the first setup, `npm run dev` is enough. The same root entrypoint supports `npm run check`, `npm run build`, `npm run preview` and `npm run test:ui`. Each site command checks the active Node version before Astro starts.
