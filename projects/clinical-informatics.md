# Clinical Informatics

I built a synthetic trial-operations workflow that moves from protocol requirements to linked data, record-level checks, operational metrics and an interactive dashboard.

The project includes:

- protocol-to-data mapping for a synthetic multicentre Phase II metabolic study;
- eight linked tables covering sites, participants, visits, laboratories, adverse events, queries, protocol deviations and milestones;
- validation for relationships, timing, completeness, plausibility and operational follow-up;
- site and study metrics calculated from the same retained records;
- reproducible Python builds, tests and GitHub Actions; and
- an interactive Streamlit dashboard.

This is a self-directed learning and demonstration project. It extends my biomedical and health-data foundation into clinical informatics, relational data design and trial-operations analysis.
