# Results overview

## Public-facing summary

 The project found that hospital-coded trajectory data carries potential to be explored for Brugada-suspect stratification, but the evidence did not justify clinical classification of such a cohort as the exemplar (Brugada Sundrome).

## High-level findings

- Routine hospital data was useful for constructing research features and asking structured questions.
- The strongest model-family signal remained modest and unstable.
- Small sample size, imbalance and limited event support were central constraints.
- The exploratory raw-code branch was methodologically useful but not stable enough to replace the main analysis route.
- The main value of the project was governed research design, not a deployable model.
